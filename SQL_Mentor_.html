DML vs DDL: what is the difference?

Think of the library. DDL builds the shelves. DML puts books on the shelves, finds them, changes them and removes them.

DMLDDL
Full nameData Manipulation LanguageData Definition Language
Works onThe data (rows) inside tablesThe structure of the database (tables and columns)
Commands hereSELECT, WHERE, ORDER BY, GROUP BY, INNER JOIN, Subqueries, INSERT, UPDATE, DELETECREATE, ALTER, TRUNCATE, DROP
Uses WHERE?Yes (SELECT, UPDATE, DELETE)No
Can it be undone?Yes, with ROLLBACK inside a transactionIn MySQL it is saved straight away, so ROLLBACK cannot undo it
Library exampleINSERT INTO Authors (author_id, author_name) VALUES (5, 'Ravi Pillai');CREATE TABLE Clubs (club_id INT PRIMARY KEY, club_name VARCHAR(50));
ResultA row is addedA table is built

SELECT only reads data. Some books put it in its own group called DQL, but this app lists it with DML.
