1. Project Objective
Develop a lightweight web-based SQL tutoring platform where students can:
•	Practice SQL queries.
•	Receive AI-generated SQL solutions and 	explanations.
•	Execute queries on a sample SQL database.
•	Obtain automatic correctness feedback.
•	Monitor their learning progress through simple 	analytics.
The system emphasizes SQL learning support rather than adaptive tutoring, aligning with the simplified architecture described in your document.

SQL Database
Instead of creating a complex university database, create a simple Library Database, because it covers almost every SQL concept.

In this :
Tables are :
1. Authors
	author_id  	int pk
	author_name 	varchar(100)
	country		varchar(50)
2. Books
	book_id 	int pk
	title 		varchar(150)
	author_id 	int fk(author tbl)
	category 	varchar(50)
	price 		float
	year 		int
3. Students
	student_id 	int pk
	name 		varchar(100)
	department 	varchar(50)
	semester 	int
4. Borrow
	borrow_id	INT PK
	student_id	INT FK
	book_id		INT FK
	borrow_date	DATE
	return_date	DATE
5. Student Progress
	progress_id	INT PK
	student_name	VARCHAR(100)
	topic		VARCHAR(50)
	attempts	INT
	correct_answers	INT
	accuracy	FLOAT
	practice_date	DATE
This table is for contribution in storing learning analytics.
